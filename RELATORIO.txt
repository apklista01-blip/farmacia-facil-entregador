1. VISAO GERAL
----------------------------------------------------------------

O App Entregador e o aplicativo (Flutter) voltado para os
entregadores da plataforma Farmacia Facil. Permite que o
entregador se cadastre, faca login, visualize pedidos prontos
para entrega, aceite entregas, acompanhe em rota e marque
como entregue, alem de consultar o historico de entregas.

Ecossistema Farmacia Facil:
  - App Usuario (farmacia.facio) - PRODUCAO
  - App Vendedor (farmacia-facil-vendedor) - PRODUCAO
  - App Admin (farmacia-facio-admin) - MVP funcional
  - App Entregador (este projeto) - FASE 3 (MVP funcional)

Projeto Firebase compartilhado: farmacia-facil-b980c
Conta: sandroprogramatattoo@gmail.com

2. STACK TECNOLOGICA
----------------------------------------------------------------

  Framework: Flutter 3.38.5 (Dart 3.10.4)
  Alvo: Web (Chrome) e compativel com mobile
  Estado: flutter_riverpod 3.3.2 (Notifier API)
  Navegacao: go_router 17.5.0
  Backend: Firebase (firebase_core 5.1.0, firebase_auth 7.0.1,
           cloud_firestore 7.1.0)
  Utilitarios: intl 0.20.3, shared_preferences 2.5.5,
               url_launcher 6.3.0
  Lints: flutter_lints 6.0.0

3. ARQUITETURA E ESTRUTURA
----------------------------------------------------------------

lib/
  main.dart                 Inicializacao Firebase + ProviderScope
  firebase_options.dart     Config do projeto farmacia-facil-b980c
  app/
    theme.dart              Tema claro (verde)
    routes.dart             GoRouter + redirecionamento por auth
  models/
    delivery_person_model.dart  Entregador (id,name,email,phone,isActive,createdAt)
    order_model.dart        Pedido (status, itens, total, entrega, pharmacyName)
  providers/
    auth_provider.dart      DeliveryAuthNotifier (login, cadastro, logout)
    orders_provider.dart    DeliveryOrdersNotifier (disponiveis, meus, aceitar, entregar)
  screens/
    auth/
      login_screen.dart     Login (email/senha) + link "Criar conta"
      register_screen.dart  Cadastro de entregador
    orders/
      available_orders_screen.dart  Pedidos disponiveis + aceitar
      my_orders_screen.dart        Em rota / concluidas
    history/
      history_screen.dart   Historico de entregas concluidas
  widgets/
    delivery_shell.dart     Shell com BottomNavigationBar

Colecoes Firestore consumidas:
  - delivery_persons  (cadastro/login/verificacao)
  - orders            (leitura e atualizacao de status)

5. FLUXO DE STATUS DO PEDIDO
----------------------------------------------------------------

  ready (pronto na farmacia)
    -> entregador aceita
  delivering (em rota)
    -> entregador marca entregue
  delivered (entregue)

Campos atualizados no Firestore:
  - deliveryPersonId (uid do entregador)
  - status (delivering / delivered)
  - updatedAt (timestamp ISO)
